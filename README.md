# Vinmec DSS — Academic Prototype

Independent Decision Support System prototype for the INS3070 final project. This is not an official Vinmec product. All hospital figures are synthetic and intended for demonstration only.

Planned stack: React, TypeScript, NestJS, PostgreSQL, Prisma and optional OpenAI API. Scope: patient-demand forecasting, resource-capacity scenarios, recommendations with human approval, and decision history.

The complete initial prototype source was prepared separately; repository setup is in progress.
